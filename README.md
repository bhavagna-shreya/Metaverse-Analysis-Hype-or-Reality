# 📈 Metaverse Analysis: Hype or Reality? (2021–2022)

---

## 🧠 Project Overview

In this project, we explore whether the Metaverse's rapid rise is based on genuine user engagement or financial speculation.  
By analyzing investments, user activity, and virtual land sales from 2021 to 2022, we apply advanced machine learning techniques to detect patterns and shifts in behavior.

---

## 🔍 Datasets Used

- **Metaverse Transactions Dataset** — Financial transaction data (2022)
- **Gaming Trends Dataset** — Daily Active Users (2010–2024)
- **Decentraland Land Sales Dataset** — Virtual land transaction prices (2021–2022)

---

## 🛠️ Key Techniques Applied

- **Data Cleaning and Preprocessing** (pandas, numpy)
- **Feature Engineering** (Investment Amount, Daily Active Users, Land Sales Price)
- **Normalization** (MinMaxScaler)
- **Clustering Algorithms**:
  - KMeans Clustering
  - Hierarchical Clustering (Dendrogram)
  - DBSCAN (Density-Based Clustering)
- **Dimensionality Reduction**:
  - Principal Component Analysis (PCA)
- **Explainable ML**:
  - Decision Tree Classifier

---

## 📈 Major Findings

- **2021:**  
  High user engagement, but low financial investment and land sales.

- **2022:**  
  Massive surge in financial investments and land transactions, despite declining user engagement.

- **Clustering Results:**  
  All ML methods (KMeans, DBSCAN, Hierarchical) confirmed **two distinct phases** — reality-driven growth in 2021 and hype-driven growth in 2022.

- **Decision Tree Insights:**  
  A simple threshold on investment and user metrics could **perfectly classify** 2021 vs. 2022 behavior.

---

## 📢 Final Conclusion

> "While financial investments and virtual land sales in the Metaverse surged dramatically in 2022, user engagement dropped.  
> Machine learning analysis consistently shows that the Metaverse shifted from reality-based adoption to hype-driven financial speculation."
